## 本地检查

```bash
cd reading
npm test
npm run build
npm run dev
```

Node.js 24.10+。阅读工具无需安装依赖，本地地址为 `http://127.0.0.1:3001`。听说工具默认也使用 3001；同时运行时可使用 `PORT=3002 npm run dev` 启动其中一个。

AI 使用服务器环境变量 `OPENAI_API_KEY`（可选 `OPENAI_MODEL`）；本地放在忽略提交的 `.env.local` 中。部署时应单独配置身份验证、数据库及自己的站点配置。
