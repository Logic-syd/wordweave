# Read Along · 跟读工作台

独立的英语阅读与逐句跟读工具，保留粉色 Read Along 页面。

- 粘贴正文、原文链接或整条推荐；多链接先选一篇。支持公开 Guardian / Cup of Jo 页面正文提取、txt/md 导入和 JSON 备份恢复。
- 紧凑播放工具栏：上一句、开始跟读、下一句、语速。声音、练习模式、跟读留白收在「播放设置」。支持留白跟读、连续听读、单句循环。
- 「AI 标注重点词」按整篇精选 3–5 个难词或自然表达，在原文中点按查看中文释义。过短或简单的材料可少于 3 个；标注结果随文章保存在当前浏览器。
- 可选 AI 分段与全文中文参考。跟读使用设备英语语音，无需调用模型。
- 文章、重点词与跟读位置使用浏览器本地存储；原有服务端材料仍能恢复到列表。服务端不保存 API Key 到学习数据。

本目录基于已部署的 Site 源码提交 `a856e084e8c287fe5a4e9c81913471204965eebf` 导出，未包含站点身份配置、密钥、个人材料、数据库或构建产物。兼容页面 `/workspace.html` 和相关文件随源码保留；当前阅读主页没有多模块导航。

## 在电脑上运行

使用 Node.js 24.10 或更新版本，在本目录运行以下命令。项目使用 Node 内置模块，无需安装依赖。

```bash
npm run dev
```

打开 <http://127.0.0.1:3001>。本地模式用于个人电脑，只监听回环地址。阅读主页文章与重点词保存在浏览器；兼容工作台材料、标记和答案保存在本机的 `.wordweave/study.sqlite`。使用 `npm test` 检查批改和保存，`npm run build` 生成 Worker。

## 使用自己的 API

在本目录创建 `.env.local`。设置 `OPENAI_API_KEY` 为自己的 OpenAI 项目密钥，再启动或重启工作台。默认模型为 `gpt-4.1-mini`，也可以用 `OPENAI_MODEL` 指定支持 Responses API 结构化输出的模型。密钥通过服务端发送，个人设置和学习记录已列入 Git 忽略规则。

导入英文或德语材料时，点击「生成中文与练习」，可按原段落生成中文辅助、理解题和口语题。提交文字回答后会逐项显示意思是否完整、改进建议和参考说法。最近的答案和分数保存在「练习记录」。听写在浏览器中逐词比对，无需模型。跟读笔记与媒体链接可随练习保存，发音由学习者自行回听。旧答案可以在记录页按当前材料补批。

## 部署

`web/` 包含阅读与练习页面，`server/ai.mjs` 处理模型请求，`worker.mjs` 处理身份和数据。托管使用 Cloudflare D1 的 `DB` 绑定和 `drizzle/` 迁移。Sites 部署需设置自己项目的 `.openai/hosting.json`、D1 绑定以及 `OPENAI_API_KEY` 服务端密钥。个人工作台应设为仅所有者可访问。

本地预览使用固定的本机身份。托管的用户身份由可信网关提供。自行提供外网访问时，需要网关完成身份验证并覆盖身份头。
