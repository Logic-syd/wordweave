## 五分钟实机测试

1. 在英文文章里点「翻译本页」，确认正文译成中文、保留部分英文、代码不变；点「恢复原文」。
2. 划选几段后翻译，确认只改变选定正文；点表达收藏，再到「文章与收藏」找到它。
3. 关闭并重开 Chrome，确认收藏还在；刷新原网页，再次翻译。
4. 用自己的 AI Key 保存设置，确认只申请所选服务域名权限；试一次有效 Key 和无效 Key，不会自动切换服务。
5. 设置中删除 Key，确认切回免费模式、收藏仍在，重新打开设置后 Key 为空。检查拒绝权限和网络失败时的提示。

额外记录：Chrome 版本、操作系统、免费翻译网络结果；检查后台休眠后不会无提示重发收费请求、从旧版更新后数据保留。测试过程中不要把 Key 或私人文章拍进截图。

## 上传时填写

- ZIP：运行 `npm run extension:release`，取 `extension/release/v0.2.1/wordweave-chrome-0.2.1.zip`。上传 ZIP 本身，不上传源码仓库，也不上传带外层文件夹的 ZIP。
- 商品文案：复制同目录 `listing.txt` 对应字段。
- 图标：`extension/static/icons/icon-128.png`。
- 单一用途：**帮助中文使用者在英文网页中阅读译文、学习保留的英文表达并保存本机词卡。**
- 权限用途：见下表。自定义 API 的可选权限按需申请；不要申请所有网页的固定读取权限。
- 隐私披露：网页内容会发送给 Google 或用户选定模型服务；标题、来源网址、原文、收藏与 Key 在本机保存。不能勾选「完全不处理用户数据」。按后台定义核对「网站内容」「浏览记录/网址」「认证信息」等相关类别，区分本机处理与第三方传输，不虚报没有数据流。
- 远程代码：全部执行脚本随安装包提供；服务返回译文/JSON，作为经过校验的内容渲染，不作为脚本执行。
- 审核说明：免费模式无需登录或邀请码。AI 是可选自带 Key 功能；不要把自己的付费 Key 粘贴进审核说明。

| 权限 | 可粘贴的用途说明 |
| --- | --- |
| `activeTab` | 用户点击插件后读取当前标签页文章或选中文字，用于主动翻译。 |
| `scripting` | 注入安装包内的内容脚本，在当前页展示学习版、词卡并恢复原文。 |
| `storage` | 在当前浏览器保存设置、API Key、文章、词卡和学习状态，不做云同步。 |
| Google 域名权限 | 用户主动点击免费翻译后，直接连接 translate.googleapis.com 获取译文。 |
| 可选 HTTPS 域名权限 | 允许用户选择自己的 OpenAI 兼容 API，实际仅请求其配置的服务域名。 |
| 可选本机 HTTP 权限 | 允许软件开发者连接自己运行的本机模型服务，不扫描其他本机服务。 |
