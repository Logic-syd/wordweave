连接你的语境

网页负责阅读，语境保存你的词卡。

填写你部署的语境网址。保存时仅请求连接这个网站的权限。

与网站环境变量 EXTENSION_ACCESS_TOKEN 一致。这是你自己设置的插件令牌，请勿填写 DeepSeek API Key。

使用方式

打开英文文章，点击浏览器工具栏的语境小精灵，选择转换整篇或选中段落。生成时可以关闭弹窗；词卡收藏会保存到网站生词本。

模型转换需要网站已配置模型 API。第一次使用先选一小段试试；相同内容和保留量会复用任务。

任务缓存

插件仅保存最近 100 个任务的编号与摘要，不在本地长期缓存正文。清除后，相同文章再次转换可能产生模型费用；网站中的文章和收藏会保留。

插件只在你主动点击转换时读取正文。插件访问令牌只保存在浏览器扩展的本地存储中，不提供给网页脚本；模型 API Key 留在网站服务端。
