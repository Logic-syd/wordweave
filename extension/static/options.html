想怎么翻译？

默认免费，无需账号。

翻译方式

由 Google 提供普通翻译，再按规则保留英文表达。服务不可用时会提示，不会自动切换到付费 AI。

Key 不会上传到语境服务器。

使用 AI 时，Key 和待译内容直接发送给你选择的服务商，不交给正在阅读的网页。

Key 仅保留在本次浏览器会话。重启浏览器、更新或重新加载插件后需要重新填写；本机存储不等于绝对安全。

API 费用由服务商收取，与聊天会员订阅分开。

请求发送至：选择服务商后显示

模型与接口设置（可选）

官方服务地址自动填写；自定义接口需兼容 OpenAI 格式。

留空会从服务商模型列表选择。可在测试连接后自行选择，费用以服务商为准。

译文会在本机缓存，再次翻译相同内容时可直接使用。

正文和 Key 会发到哪里？

点击翻译会发送待译正文。免费模式发给 Google；AI 模式直接发给你设置的 AI 服务；测试连接会使用 Key 查询模型列表。保存设置不会调用模型。Key 不会交给正在阅读的网页，也不会上传到语境网站。可以随时清除翻译缓存或删除保存的 Key。本版不提供长期记住 Key。
