语境插件隐私说明

适用于插件 0.3.0，更新于 2026 年 11 月 20 日。

翻译时，正文会发给谁？

你主动点击翻译后，插件读取当前网页正文或选中的段落。免费模式将待翻译文字发送给 Google（translate.googleapis.com）；AI 模式将正文发送给你选择的 OpenAI、Anthropic、xAI、DeepSeek 或自定义服务。新安装不会预选 AI 服务商。插件不会自动翻译浏览过的所有网页，也不收集完整浏览历史。

免费服务使用带有待译文字的 HTTPS 请求参数，服务商可能记录这些请求。AI 模式使用你填写的 API Key 认证。点击「测试连接」，或未指定模型时首次翻译，会向所选服务查询模型列表；保存设置不会调用模型。AI 翻译会发送所选段落和翻译要求，不额外附带网页标题或来源网址；正文里包含的信息仍会随正文发送。服务商会接收 IP 地址等连接信息，其保存、使用和删除规则由该服务商决定。请查看对应隐私政策，不要翻译你无权发送给该服务的机密内容。

哪些东西保存在本机？

点击词卡发音时，词语交由浏览器或系统的英语语音服务朗读。部分语音可能使用在线服务，其数据处理取决于浏览器、系统和所选语音。

网页标题、来源网址、原文与译文在当前浏览器中作为翻译缓存保存（最多 20 条、3 MiB），旧缓存会自动淘汰。翻译偏好、服务地址和模型名称保存在本机，不使用浏览器同步。

API Key 仅保存在扩展的浏览器会话存储（chrome.storage.session），不写入长期设置或翻译缓存。 关闭设置页或后台暂时休眠不会清除 Key；重启浏览器、禁用、更新或重新加载插件后需重新填写。 仅插件受信任的页面和后台可以访问，不交给网页或内容脚本。 这不是加密密码库，无法保证受损设备或受损插件上的密钥安全。

从旧版升级时，会将原先长期保存的 Key 转入本次会话并移除长期存储中的副本，同时清除旧版网站访问令牌。 切换服务商或修改接口地址会清空待填写的 Key，保存前会显示接收请求的域名。

这些记录不通过语境网站同步，不发送给语境运营者。插件未加入广告或行为统计服务。插件记录与网页版记录互相独立。

权限用来做什么？

当前标签页和脚本权限用于在你点击后读取正文、展示译文；存储权限用于保存设置与翻译缓存。Google 域名权限用于免费翻译。可选的网站权限仅在配置 AI 时申请对应服务地址；自定义服务使用 HTTPS，本机调试地址允许 HTTP。

如何删除？

在设置页点击「清除 Key」会清除保存的凭据并切回免费翻译，翻译缓存保留。已经进行的请求可能仍会完成。若要让 Key 失效，请到模型服务商控制台撤销它。

在设置页点击「清除翻译缓存」可以删除当前翻译缓存。旧版本已保存的文章和收藏暂时保留，不再提供文章库界面；清除新缓存不会删除这些旧数据。卸载插件会删除全部插件本机数据，包括 API Key；不会撤回已经发送给服务商的请求。

联系与变更

功能或数据处理变化时，会随版本更新此说明。问题请到项目问题页联系维护者。该页面公开，请勿提交 Key、密码或私人文章。
