语境插件隐私说明

适用于插件 0.2.1，更新于 2026 年 11 月 6 日。

翻译时，正文会发给谁？

你主动点击翻译后，插件读取当前网页正文或选中的段落。免费模式将待翻译文字发送给 Google（translate.googleapis.com）；AI 模式将正文发送给你配置的模型服务，默认地址为 DeepSeek。插件不会自动翻译浏览过的所有网页，也不收集完整浏览历史。

免费服务使用带有待译文字的 HTTPS 请求参数，服务商可能记录这些请求。AI 模式还会向所选服务查询模型列表，并使用你填写的 API Key 认证。服务商会接收 IP 地址等连接信息，其保存、使用和删除规则由该服务商决定。请查看对应隐私政策，不要翻译你无权发送给该服务的机密内容。

哪些东西保存在本机？

文章标题、来源网址、原文、学习版、收藏、学习状态与设置保存在当前浏览器的插件本地存储。API Key 也保存在本地，仅插件的受信任页面和后台可访问，不交给网页或内容脚本。本地存储不是加密密码库。

这些记录不通过语境网站同步，不发送给语境运营者。插件未加入广告或行为统计服务。插件记录与网页版记录互相独立。

权限用来做什么？

当前标签页和脚本权限用于在你点击后读取正文、展示译文；存储权限用于保存设置、文章和收藏。Google 域名权限用于免费翻译。可选的网站权限仅在配置 AI 时申请对应服务地址；自定义服务使用 HTTPS，本机调试地址允许 HTTP。

如何删除？

在设置页点击「删除已保存的 Key」会清除保存的凭据并切回免费翻译，文章和收藏保留。已经进行的请求可能仍会完成。若要让 Key 失效，请到模型服务商控制台撤销它。

在「我的文章与收藏」中删除文章或取消收藏。卸载插件会删除全部插件本机数据，包括 API Key；不会撤回已经发送给服务商的请求。

联系与变更

功能或数据处理变化时，会随版本更新此说明。问题请到项目问题页联系维护者。该页面公开，请勿提交 Key、密码或私人文章。
