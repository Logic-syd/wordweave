# 语境浏览器插件

打开英文网页，点「翻译本页」。默认免费，不用登录、不用邀请码。

## 安装

1. 在网站的「浏览器插件」页下载，解压。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开「开发者模式」，点「加载已解压的扩展程序」，选刚解压的文件夹。

更新时重新下载、解压，再在扩展页点「重新加载」。目前支持电脑 Chrome / Edge，尚未上架扩展商店。

## 使用

- **免费翻译**：打开文章 → 点小精灵 → 翻译本页。也可只翻译选中的段落。
- **AI 翻译**：设置 → 选 AI → 填自己的 DeepSeek Key → 保存。费用由自己的模型账户承担。
- **收藏**：点英文表达 → 收藏。在插件的「我的文章与收藏」里查看。

文章与收藏保存在当前浏览器的插件里，不同步到网站；网站已有的学习记录不受影响。卸载插件会删除本机数据。

<details>
<summary>免费与 AI 有什么区别？</summary>

免费模式使用 Google 的公开网页翻译接口，无需 API Key；按规则挑选英文表达，只在译文能明确对应时保留，不会编造 AI 语法讲解。无法对应时显示普通译文，并可查看原文。该接口不是有服务承诺的官方付费 API，网络限制、限流或服务变更可能导致失败。

AI 模式直接连接使用者选择的 OpenAI 兼容服务，生成中文与英文表达结合的学习版。默认连接 DeepSeek；模型列表自动查询，不硬编码模型名称。高级设置可指定模型与 API 地址。没有有效 Key、余额不足或服务失败时明确报错，不使用站主的 Key，也不自动改用另一种翻译方式。

</details>

<details>
<summary>隐私与限制</summary>

- 只有主动点击翻译才发送选定正文；免费模式发给 Google，AI 模式发给所选模型服务。代码块保留，行内代码与链接受保护。
- API Key 仅保存在扩展的受信任本地存储中，翻译时用于直连所选模型服务；不会发给语境服务器、内容脚本或网页。
- 支持普通网页正文；PDF、浏览器内部页面、iframe、Shadow DOM 和复杂交互应用不在本版范围。最多 80 段、20,000 字符，超限请选一节正文。
- 相同正文、设置和模型配置复用本机结果；失败需要手动重试。后台被浏览器中断时不会自动重新调用收费 API。
- 原文与翻译安全渲染，模型没有执行工具。译文与语言讲解仍可能不准确，可以逐段对照原文。

</details>

## 开发与验证

```bash
npm ci
npm run extension:build
npm run typecheck
npm run lint
npm test
npm run test:extension:dom
npm run test:extension:ui
npm run test:extension -- --content-harness
```

构建输出 `extension/dist/` 与 `public/downloads/wordweave-extension.zip`。网站 `npm run build` 会同时打包插件。

测试明确模拟免费翻译和 AI 服务，检查真实插件后台、内容脚本、代码保护、密钥隔离、缓存与本地收藏，不消耗模型额度。云浏览器策略禁止安装未打包扩展时，内容脚本测试不代表已验证真实安装、权限弹窗和 MV3 后台生命周期。
