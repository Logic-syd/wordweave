# Wordweave 听说工作台

面向中文使用者的工作英语听说与 A1–B1 德语练习工具。进入首页即可开始一道短练习。5 分钟模式听一段、概括重点。20 分钟模式按段完成理解、跟读、听写、复述和口语回答。

## 在电脑上运行

使用 Node.js 24.10 或更新版本，在本目录运行以下命令。项目使用 Node 内置模块，无需安装依赖。

```bash
npm run dev
```

打开 <http://127.0.0.1:3001>。本地模式用于个人电脑，只监听回环地址。材料、标记和答案保存在本机的 `.wordweave/study.sqlite`。使用 `npm test` 检查批改和保存，`npm run build` 生成 Worker。

## 使用自己的 API

在本目录创建 `.env.local`。设置 `OPENAI_API_KEY` 为自己的 OpenAI 项目密钥，再启动或重启工作台。默认模型为 `gpt-4.1-mini`，也可以用 `OPENAI_MODEL` 指定支持 Responses API 结构化输出的模型。密钥通过服务端发送，个人设置和学习记录已列入 Git 忽略规则。

导入英文或德语材料时，点击「生成中文与练习」，可按原段落生成中文辅助、理解题和口语题。提交文字回答后会逐项显示意思是否完整、改进建议和参考说法。最近的答案和分数保存在「练习记录」。听写在浏览器中逐词比对，无需模型。跟读笔记与媒体链接可随练习保存，发音由学习者自行回听。旧答案可以在记录页按当前材料补批。

## 部署

`web/` 包含阅读与练习页面，`server/ai.mjs` 处理模型请求，`worker.mjs` 处理身份和数据。托管使用 Cloudflare D1 的 `DB` 绑定和 `drizzle/` 迁移。Sites 部署需设置自己项目的 `.openai/hosting.json`、D1 绑定以及 `OPENAI_API_KEY` 服务端密钥。个人工作台应设为仅所有者可访问。

本地预览使用固定的本机身份。托管的用户身份由可信网关提供。自行提供外网访问时，需要网关完成身份验证并覆盖身份头。
